# Kits de Memes e Piadas — Makuva TV

Coleção de roteiros prontos para produzir vídeos curtos (30 segundos, 3 clipes, formato 9:16) focados no humor do cotidiano moçambicano. Cada kit inclui storyboard, narração em português de Moçambique, legendas e resumo do prompt de geração.

Estilo padrão: **Style 1 · Classic Minimalist** (fundo branco ou preto, palito simples).  
Cores de destaque: **verde vivo, vermelho forte, amarelo brilhante**.

## Como produzir cada kit

1. Escolha um kit acima.
2. Abra o arquivo `prompts_geracao.md` do vídeo 1 como modelo e adapte o prompt para o novo tema.
3. Gere os 3 clipes (Google Flow, Runway, Luma ou Kling).
4. Monte no CapCut ou Premiere com narração em português de Moçambique.
5. Publique no YouTube como Shorts com thumbnail das cores verde, vermelho, amarelo.
