# Prompts Fase B — Vídeo 22: TDM e Internet (2)

Copie e cole cada prompt separadamente na ferramenta de geração de vídeo (Google Flow, Runway, Luma ou Kling). Cada prompt gera um clipe de ~10 segundos.

## Clipe 1 — Senha do Wi-Fi mudou (0–10s)

```
Minimalist 2D animated stick figure on pure white background. Stick figure holds phone, tries to connect to neighbor Wi-Fi, wrong password, error message. Small red signal bar accent visible. Hollow circular head, black stick limbs, uniform medium line weight. Simple black lines, smooth 2D animation style. 9:16 vertical aspect ratio, 10 seconds duration. No speech bubbles, no text, no dialogue boxes.
```

## Clipe 2 — Sem internet, fiquei off (10–20s)

```
Same minimalist 2D animated stick figure holding phone on white background. Figure tries multiple times, no internet connection, looks frustrated and disconnected. White stick figure, black stick limbs, smooth 2D animation. 9:16 vertical aspect ratio, 10 seconds duration. No speech bubbles, no text, no dialogue boxes.
```

## Clipe 3 — Vizinho não quer dar (20–30s)

```
Same stick figure walks to neighbor house, asks for new password, neighbor shakes head and closes door, figure walks away. Hollow circular head, black stick limbs, uniform medium line weight. Simple black lines, vibrant colors, smooth 2D animation style. 9:16 vertical aspect ratio, 10 seconds duration. No speech bubbles, no text, no dialogue boxes.
```

## Regras de geração (não alterar)
- Proporção: 9:16 vertical
- Duração: ~10 segundos por clipe
- Nenhum texto, número ou interface na cena
- Personagem consistente (mesma cabeça, mesmos membros, mesma linha)
- Nenhum membro ocioso por mais de 2–3 segundos
- Cores apenas com nomes comuns: branco, preto, vermelho
- Não usar hex, RGB ou Pantone

## Após gerar
Baixe os 3 clipes (MP4) e monte no CapCut, Premiere ou editor que preferir. Adicione:
1. Narração em português de Moçambique
2. Legendas sincronizadas
3. Efeito sonoro de erro de conexão (opcional)
4. Thumbnail com cores verde, vermelho, amarelo
