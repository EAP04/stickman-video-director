# Prompts Fase B — Vídeo 11: Casamento e Dote

Copie e cole cada prompt separadamente na ferramenta de geração de vídeo (Google Flow, Runway, Luma ou Kling). Cada prompt gera um clipe de ~10 segundos.

## Clipe 1 — Mesa com sogro, primeiro item do dote (0–10s)

```
Minimalist 2D animated stick figure on pure white background. Stick figure sits at table with father-in-law figure, paper with list on table, first dowry item mentioned. Hollow circular head, black stick limbs, uniform medium line weight. Simple black lines, smooth 2D animation style. 9:16 vertical aspect ratio, 10 seconds duration. No speech bubbles, no text, no dialogue boxes.
```

## Clipe 2 — Lista cresce, mais itens (10–20s)

```
Same minimalist 2D animated stick figure at table on white background. List gets longer with more items added, figure looks at list with worried expression. Small yellow paper accent visible. White stick figure, black stick limbs, smooth 2D animation. 9:16 vertical aspect ratio, 10 seconds duration. No speech bubbles, no text, no dialogue boxes.
```

## Clipe 3 — Vai pensar, sai da mesa (20–30s)

```
Same stick figure stands up from table, says needs to think, walks away from negotiation. Hollow circular head, black stick limbs, uniform medium line weight. Simple black lines, vibrant colors, smooth 2D animation style. 9:16 vertical aspect ratio, 10 seconds duration. No speech bubbles, no text, no dialogue boxes.
```

## Regras de geração (não alterar)
- Proporção: 9:16 vertical
- Duração: ~10 segundos por clipe
- Nenhum texto, número ou interface na cena
- Personagem consistente (mesma cabeça, mesmos membros, mesma linha)
- Nenhum membro ocioso por mais de 2–3 segundos
- Cores apenas com nomes comuns: branco, preto, amarelo
- Não usar hex, RGB ou Pantone

## Após gerar
Baixe os 3 clipes (MP4) e monte no CapCut, Premiere ou editor que preferir. Adicione:
1. Narração em português de Moçambique
2. Legendas sincronizadas
3. Efeito sonoro de papel sendo desenrolado ou caneta (opcional)
4. Thumbnail com cores verde, vermelho, amarelo
