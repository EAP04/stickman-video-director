# Prompts Fase B — Vídeo 127: Namoro e WhatsApp (10)

Copie e cole cada prompt separadamente na ferramenta de geração de vídeo (Google Flow, Runway, Luma ou Kling). Cada prompt gera um clipe de ~10 segundos.

## Clipe 1 — Enviei a mensagem (0–10s)

```
Minimalist 2D animated stick figure on white background with bedroom with bed, phone on nightstand and window. Stick figure holds phone, sends message in WhatsApp, sees message was deleted before being read, figure looks confused. Small red deleted message accent visible. Hollow circular head, black stick limbs, uniform medium line weight. Simple black lines, smooth 2D animation style. 9:16 vertical aspect ratio, 10 seconds duration. No speech bubbles, no text, no dialogue boxes.
```

## Clipe 2 — Apagou antes de ler (10–20s)

```
Same minimalist 2D animated stick figure holding phone on white background with bedroom with bed, phone on nightstand and window. Figure checks WhatsApp again, message shows deleted before read, looks sad. White stick figure, black stick limbs, smooth 2D animation. 9:16 vertical aspect ratio, 10 seconds duration. No speech bubbles, no text, no dialogue boxes.
```

## Clipe 3 — Apago (20–30s)

```
Same stick figure deletes the WhatsApp chat, puts phone away, walks away looking defeated. Hollow circular head, black stick limbs, uniform medium line weight. Simple black lines, vibrant colors, smooth 2D animation style. 9:16 vertical aspect ratio, 10 seconds duration. No speech bubbles, no text, no dialogue boxes.
```

## Regras de geração (não alterar)
- Proporção: 9:16 vertical
- Duração: ~10 segundos por clipe
- Nenhum texto, número ou interface na cena
- Personagem consistente (mesma cabeça, mesmos membros, mesma linha)
- Nenhum membro ocioso por mais de 2–3 segundos
- Cores apenas com nomes comuns: branco, preto, vermelho
- Não usar hex, RGB ou Pantone

## Após gerar
Baixe os 3 clipes (MP4) e monte no CapCut, Premiere ou editor que preferir. Adicione:
1. Narração em português de Moçambique
2. Legendas sincronizadas
3. Efeito sonoro de WhatsApp (opcional)
4. Thumbnail com cores verde, vermelho, amarelo
