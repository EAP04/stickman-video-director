# Makuva TV — Organização do Projeto

Canal de piadas e memes de Moçambique em formato stickman (YouTube Shorts).

## Pastas

| Pasta | Conteúdo |
|-------|----------|
| `00_canal/` | Configurações fixas do canal, identidade visual, playlists |
| `01_ativos/logos/` | Logos e símbolos da marca (SVG) |
| `01_ativos/thumbnails/` | Miniaturas de vídeo (SVG) |
| `02_roteiros/video_01_luz_viu/` | Proposta, roteiro e prompts do vídeo 1 |
| `03_producao/video_01_luz_viu/` | Vídeo em produção: instruções, clipes, narração, montagem |
| `04_publicados/` | Vídeos já publicados no YouTube |
| `05_controle/` | Cronograma, métricas e versões da marca |

## Como usar

- Cada vídeo novo cria sua própria subpasta numerada em `02_roteiros/` e `03_producao/`.
- Quando publicar, mova a pasta de `03_producao/` para `04_publicados/`.
- Os arquivos SVG precisam ser convertidos para PNG antes de enviar ao YouTube.
